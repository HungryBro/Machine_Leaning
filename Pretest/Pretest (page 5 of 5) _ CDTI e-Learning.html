เขียนฟังก์ชัน gradient_descent(X, y, theta, alpha, num_iters) เพื่อปรับปรุงค่าพารามิเตอร์ 𝜃θ โดยใช้ Gradient Descent สำหรับ Linear Regression โดย:

Input:
X คือ เมทริกซ์ข้อมูลตัวแปร (ไม่รวม Intercept) ขนาด 𝑚×𝑛m×n โดยที่ 𝑚m คือจำนวนตัวอย่าง และ 𝑛n คือจำนวนตัวแปร (ชนิดข้อมูล: numpy.ndarray)
y คือ เวกเตอร์ค่า output ขนาด 𝑚m (ชนิดข้อมูล: numpy.ndarray)
theta คือ เวกเตอร์พารามิเตอร์ ขนาด 𝑛+1n+1 โดยค่าแรกสุดคือค่าของ Intercept (ชนิดข้อมูล: numpy.ndarray)
alpha คือ อัตราการเรียนรู้ (Learning Rate) (ชนิดข้อมูล: float)
num_iters คือ จำนวนรอบของการปรับปรุงพารามิเตอร์ (ชนิดข้อมูล: int)

Output:
theta คือ พารามิเตอร์ที่ถูกปรับปรุงหลังการเรียนรู้ (ชนิดข้อมูล: numpy.ndarray)
J คือ ค่าความสูญเสียในแต่ละรอบ (ชนิดข้อมูล: list หรือ numpy.ndarray)

การทำงาน:
อัปเดต 𝜃θ ด้วยสมการ
𝜃:=𝜃−𝛼∇𝐽(𝜃)θ:=θ−α∇J(θ)
 เมื่อ
∇𝐽(𝜃)=1𝑚𝑋𝑇(𝑦̂ −𝑦)∇J(θ)=1mXT(y^−y)


Write a function gradient_descent(X, y, theta, alpha, num_iters) to update the parameter vector 𝜃θ using Gradient Descent for a Linear Regression problem:

Input:
X is the matrix of input features (excluding the intercept term) of size 𝑚×𝑛m×n, where 𝑚m is the number of samples and 𝑛n is the number of features (Data type: numpy.ndarray)
y is the output value vector of size 𝑚m (Data type: numpy.ndarray)
theta is the parameter vector of size 𝑛+1n+1, where the first element represents the intercept (Data type: numpy.ndarray)
alpha is the learning rate (Data type: float)
num_iters is the number of iterations for updating the parameters (Data type: int)

Output:
theta is the updated parameter vector after training (Data type: numpy.ndarray)
J is the list (or numpy array) containing the cost value at each iteration (Data type: list or numpy.ndarray)

Functionality:
Update 𝜃θ using the equation:
𝜃:=𝜃−𝛼∇𝐽(𝜃)θ:=θ−α∇J(θ)
 where
∇𝐽(𝜃)=1𝑚𝑋𝑇(𝑦̂ −𝑦)∇J(θ)=1mXT(y^−y)
